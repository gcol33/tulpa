# Compute nearest neighbors for spatiotemporal NNGP

Compute nearest neighbors for spatiotemporal NNGP

## Usage

``` r
compute_st_nngp_neighbors(coords, time, k)
```

## Arguments

- coords:

  N x 2 matrix of coordinates

- time:

  N-vector of time values

- k:

  Number of nearest neighbors

## Value

List with neighbor structure
