# Posterior predictive checks for tulpa models

Visual and numerical checks comparing observed data to posterior
predictive distributions. Essential for assessing model fit.

## Value

The functions documented in this family return a `ggplot` object
([`pp_check()`](https://gillescolling.com/tulpa/reference/pp_check.md))
or a `tulpa_prior_predict` object
([`prior_predict()`](https://gillescolling.com/tulpa/reference/prior_predict.md));
see each function's own help page.
