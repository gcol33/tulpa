# Generate random effects for simulation

Generate random effects for simulation

## Usage

``` r
sim_random_effects(n_groups, sigma = 0.5, type = "iid")
```

## Arguments

- n_groups:

  Number of groups

- sigma:

  Standard deviation

- type:

  Type of random effects: "iid" (default), "car", "ar1"

## Value

Numeric vector of random effects
